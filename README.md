# Топологические признаки и обучаемые топологические слои

В этой папке собраны два законченных эксперимента на реальных рукописных цифрах OptDigits: исходный датасет, код, настройки, обученные модели, предсказания и отчёты. Для проверки сохранённых результатов скачивать данные не требуется.

## Полученные результаты

| Эксперимент | Результат | Статус |
|---|---|---|
| Фиксированные топологические признаки, две сети по 508 параметров | 96,36% против 95,42% у геометрического контроля; на 20,6% меньше ошибок | Тест WDEP, 943 изображения, среднее 10 запусков; авторы почерка представлены в обучении |
| Обучаемый эйлеров слой | 95,38% против 95,00% у замороженного слоя и 96,51% у лучшей проверенной CNN | Валидационный эксперимент; преимущество над CNN не получено |

Первый результат относится к конкретному сравнению маленьких сетей и заранее вычисляемым признакам. Он не означает превосходства над всеми компактными CNN. Во втором эксперименте фильтры и пороги топологического слоя обучаются через ошибку классификации; все модели получают одинаковые изображения 8×8.

## Быстрая проверка

Нужны Python 3.12 и системная утилита `gzip`, умеющая читать Unix `.Z` (есть в обычных установках macOS/Linux). Проверенная платформа: macOS arm64, CPU.

### Через uv

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/), затем из этой папки выполните:

```bash
uv sync --locked
uv run --locked python verify_results.py
```

`uv` создаёт `.venv`, устанавливает зависимости и при необходимости загружает Python 3.12. Активировать окружение вручную не требуется. Прямые зависимости имеют те же версии, что в исходном эксперименте; `uv.lock` дополнительно фиксирует транзитивные зависимости. В Git следует сохранять `pyproject.toml`, `uv.lock` и `.python-version`; `.venv` и кеши исключены через `.gitignore`.

Любой отдельный скрипт можно запускать тем же способом. Например, справка об обучении:

```bash
uv run --locked python outputs/tiny_topology/tiny_confirmation.py --help
uv run --locked python outputs/learned_topology/pilot.py --help
```

Исторические служебные скрипты продолжения работы могут ссылаться на прежнее окружение `work/real-env`. Для работы через `uv` используйте непосредственно скрипты обучения и проверки, перечисленные в инструкциях.

### Через venv и pip

Прежний способ также поддерживается; версии прямых зависимостей перечислены в `requirements.txt`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python verify_results.py
```

Проверка сверяет контрольные суммы всех перенесённых файлов, затем работает с временной копией материалов. Исторические протоколы и результаты остаются неизменными. Итог записывается в `verification/latest.json`.

Для эксперимента с фиксированными признаками заново вычисляются точности и статистический критерий по сохранённым предсказаниям; проверяются данные, протокол и отсутствие полных совпадений картинок между обучением и тестом. Для обучаемого слоя заново загружаются все 102 модели и вычисляются их валидационные предсказания. Эта команда **не переобучает модели с нуля**.

## Повторить успешное сравнение с нуля

Чтобы заново обучить именно две модели, давшие 96,36% против 95,42%, выполните из корня проекта:

```bash
uv sync --locked
uv run --locked python reproduce_primary.py --workers 4
```

Команда пересчитывает признаки из исходных изображений и обучает **20 новых сетей**: топологический и геометрический варианты по 10 инициализаций. Старые веса для обучения не используются. Архитектуры и настройки уже выбраны исходным валидационным поиском; повторять все 744 пробных обучения здесь не требуется.

| Настройка | Топология | Геометрия |
|---|---:|---:|
| Обучаемых параметров | 508 | 508 |
| Архитектура | 72→6→10, ReLU | 72→6→10, ReLU |
| Скорость обучения AdamW | 0,003 | 0,01 |
| Число эпох | 105 | 33 |
| Инициализации | 0–9 | 0–9 |

Обе сети обучаются на всех 2880 изображениях TRA+CV с batch size 256 и weight decay 0,01. Топологическая сеть получает 64 усреднённых пикселя и 8 признаков компонент/отверстий; геометрическая — те же пиксели и 8 признаков площадей/периметров. Стандартизация обучается только на TRA+CV. WDEP (943 изображения) используется после сохранения всех новых весов.

Каждый запуск создаёт отдельную папку `runs/primary-ДАТА/`:

- `report_ru.md` — короткая таблица результата;
- `result.json` — точности всех запусков, разность, интервал и сравнение с историческими предсказаниями;
- `models/` — 20 новых обученных моделей;
- `predictions.npz` — новые предсказания;
- `run_protocol.json`, `weights_receipt.json`, `prediction_receipt.json` — настройки и контрольные суммы.

Для собственного имени папки добавьте `--output runs/my-repeat`. Папка должна быть новой: существующие результаты команда не перезаписывает. Для меньшей нагрузки используйте `--workers 1`. Каталог `runs/` исключён из Git, исходные материалы остаются на месте.

Исторический результат: **топология 96,3627%, геометрия 95,4189%, разность +0,9438 п.п., 10/10 положительных пар**. Это средняя точность десяти отдельных сетей, не ансамбля. На другой платформе численные результаты могут отличаться; скрипт явно сохраняет сравнение с исходным запуском.

Это повторное обучение выбранной пары. `verify_results.py` проверяет уже сохранённые результаты и не выполняет такого обучения. Повтор на уже известном WDEP не является новым независимым подтверждением гипотезы.

## Повторить эксперимент с обучаемым топологическим слоем

Для полного повторного обучения второго эксперимента:

```bash
uv sync --locked
uv run --locked python reproduce_learned.py --workers 4
```

Команда заново обучает **все 102 модели**: первоначальные 72 варианта и дополнительные 30 однополевых вариантов. В сравнении участвуют обучаемый и замороженный эйлеров слой, слои площадей и периметров, MLP и обычные CNN. Для каждого варианта проверяются две скорости обучения и три инициализации. `--workers` задаёт число параллельных процессов для всей сетки; для меньшей нагрузки можно указать 1.

Входные массивы заново вычисляются из исходных TRA/CV и проверяются на точное совпадение с исходным экспериментом. Старые веса и предсказания не копируются в новую рабочую папку и не участвуют в обучении. Формула эйлерова слоя и градиенты проверяются отдельным запуском. После обучения заново загружаются все 102 контрольные точки и проверяются их предсказания, число параметров и изменения обучаемой части слоя.

Результаты сохраняются в новой папке `runs/learned-ДАТА/`:

- `report_ru.md` — сравнительная таблица;
- `result.json` — лучшие конфигурации и сравнение новых предсказаний с исходными;
- `status.json` — число завершённых обучений;
- `work/learned_topology/jobs/` и `single_field_jobs/` — новые веса, кривые обучения и предсказания;
- `outputs/learned_topology/results_audit.json` — проверка всех новых моделей;
- `math_checks/layer_checks.json` — новый протокол математических и градиентных проверок;
- `logs/` — подробные журналы проверок.

Можно задать имя новой папки: `--output runs/learned-repeat`. Существующая папка не перезаписывается. Исходные скрипты, протоколы и результаты остаются на месте; скопированные протоколы служат ссылкой на исторические настройки, а текущий запуск описан отдельно в `run_protocol.json`.

Ожидаемые средние точности CV в исходном окружении:

| Модель | Точность |
|---|---:|
| Однополевой замороженный эйлеров слой | 95,00% |
| Однополевой обучаемый эйлеров слой | 95,38% |
| Однополевой слой площади и периметра | 95,70% |
| Лучшая проверенная обычная CNN | 96,51% |

Здесь **1934 обучающих и 946 валидационных изображения**, а не тест WDEP из первого эксперимента. Скорость обучения и контрольная точка выбираются по этой же CV. Исходный результат показал обучаемость слоя, но не преимущество над CNN; повтор не предполагает заранее положительного исхода.

Если нужно только проверить сохранённые результаты без обучения, используйте `uv run --locked python verify_results.py`: эта команда проверит оба эксперимента во временной копии.

## Полный поиск и остальные эксперименты

Порядок первого эксперимента описан в `outputs/tiny_topology/README_reproduction.md`. Для допустимых MLP-конфигураций используется `collect_tiny_mlp.py`, а не исходная неподфильтрованная сетка. Для второго эксперимента используются `pilot.py` и `single_field_pilot.py`.

Скрипты сохраняют результаты отдельных запусков и могут пропускать уже выполненные задания. Полное новое обучение следует проводить в отдельной копии с новыми протоколами и выходными файлами; нельзя незаметно изменять зафиксированный эксперимент. С нуля в заново установленном окружении вся исследовательская серия повторно не запускалась. При переносе проверены имеющиеся результаты с установленными версиями библиотек.

Тестовые разбиения уже использованы в исследовании: дальнейший выбор модели по ним не будет новым независимым подтверждением.
