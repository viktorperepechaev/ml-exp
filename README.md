# Топологические признаки и обучаемые топологические слои

В этой папке собраны два законченных эксперимента на реальных рукописных цифрах OptDigits: исходный датасет, код, настройки, обученные модели, предсказания и отчёты. Для проверки сохранённых результатов скачивать данные не требуется.

## Полученные результаты

| Эксперимент | Результат | Статус |
|---|---|---|
| Фиксированные топологические признаки, две сети по 508 параметров | 96,36% против 95,42% у геометрического контроля; на 20,6% меньше ошибок | Тест WDEP, 943 изображения, среднее 10 запусков; авторы почерка представлены в обучении |
| Обучаемый эйлеров слой | 95,38% против 95,00% у замороженного слоя и 96,51% у лучшей проверенной CNN | Валидационный эксперимент; преимущество над CNN не получено |

Первый результат относится к конкретному сравнению маленьких сетей и заранее вычисляемым признакам. Он не означает превосходства над всеми компактными CNN. Во втором эксперименте фильтры и пороги топологического слоя обучаются через ошибку классификации; все модели получают одинаковые изображения 8×8.

## Быстрая проверка

Нужны Python 3.12 и системная утилита `gzip`, умеющая читать Unix `.Z` (есть в обычных установках macOS/Linux). Проверенная среда: macOS arm64, CPU. Версии пакетов зафиксированы в `requirements.txt`.

Из этой папки:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python verify_results.py
```

Проверка сверяет контрольные суммы всех перенесённых файлов, затем работает с временной копией материалов. Исторические протоколы и результаты остаются неизменными. Итог записывается в `verification/latest.json`.

Для эксперимента с фиксированными признаками заново вычисляются точности и статистический критерий по сохранённым предсказаниям; проверяются данные, протокол и отсутствие полных совпадений картинок между обучением и тестом. Для обучаемого слоя заново загружаются все 102 модели и вычисляются их валидационные предсказания. Эта команда **не переобучает модели с нуля**.

## Где что лежит

- `outputs/tiny_topology/tiny_networks_report_ru.md` — подробный отчёт об успешном сравнении сетей по 508 параметров.
- `outputs/tiny_topology/README_reproduction.md` — порядок обучения, выбора моделей и тестирования первого эксперимента.
- `outputs/tiny_topology/` — код первого эксперимента, протоколы, предсказания и результаты аудита.
- `outputs/learned_topology/report_ru.md` — отчёт об обучаемом слое, формулы, таблица контролей и ограничения.
- `outputs/learned_topology/euler_layer.py` и `single_field.py` — реализация обучаемого слоя и моделей.
- `outputs/learned_topology/pilot.py` и `single_field_pilot.py` — обучение второго эксперимента.
- `outputs/real_topology/` и `outputs/topology_complement/` — исходный загрузчик и необходимые модули подготовки признаков.
- `work/real_data/optdigits.zip` — исходный датасет UCI, включая официальные разбиения.
- `work/real_data/optdigits_complement_trainval_v1.npz` — подготовленные признаки TRA/CV.
- `work/tiny_topology/` — промежуточные результаты и сохранённые модели первого эксперимента.
- `work/learned_topology/` — подготовленные TRA/CV и модели второго эксперимента.
- `TRANSFER_MANIFEST.json` — контрольные суммы материалов и двух исходных архивов.

## Повторение обучения

Порядок первого эксперимента описан в `outputs/tiny_topology/README_reproduction.md`. Для допустимых MLP-конфигураций используется `collect_tiny_mlp.py`, а не исходная неподфильтрованная сетка. Для второго эксперимента используются `pilot.py` и `single_field_pilot.py`.

Скрипты сохраняют результаты отдельных запусков и могут пропускать уже выполненные задания. Полное новое обучение следует проводить в отдельной копии с новыми протоколами и выходными файлами; нельзя незаметно изменять зафиксированный эксперимент. С нуля в заново установленном окружении вся исследовательская серия повторно не запускалась. При переносе проверены имеющиеся результаты с установленными версиями библиотек.

Тестовые разбиения уже использованы в исследовании: дальнейший выбор модели по ним не будет новым независимым подтверждением.
