# Обучаемый топологический слой: реализация и результат на OptDigits

**Получен работающий слой, обучающий топологическое представление через ошибку классификации. Преимущества по точности над лучшей из проверенных обычных CNN не получено:** 95,38% против 96,51% на валидации. Это исследовательский результат на ранее использовавшейся выборке, без нового независимого теста и без заявления научного приоритета.

## Что именно обучается

В лучшем из двух проверенных топологических вариантов одна свёртка 3×3 создаёт поле

\[
z_p=(K*X)_p+b.
\]

Пиксель считается замкнутым квадратом. Для каждого порога комплекс содержит квадраты с высотой не ниже порога и все их граничные клетки. Высота вершины или ребра — максимум высот инцидентных квадратов, \(h(s)=\max_{p\supseteq s}z_p\). Слой вычисляет четыре значения:

\[
\Phi_k(X)=\sum_{s}(-1)^{\dim s}\,
\sigma\!\left(\frac{h(s)-\tau_k}{0.1}\right),\qquad k=1,\ldots,4.
\]

**Обучаются девять коэффициентов свёртки, её смещение и четыре порога.** Знаки в сумме зафиксированы топологической формулой. При жёстком пороге она равна эйлеровой характеристике \(\chi=V-E+F=\beta_0-\beta_1\): число компонент минус число отверстий. При сглаживании выражение точно равно ожидаемой эйлеровой характеристике при общем логистическом возмущении порога. Доказательство и устройство двухполевого варианта — в `mathematics_ru.md`.

Путь вычисления: **изображение → обучаемая свёртка → дифференцируемая эйлерова сумма → классификатор**. Дополнительно в классификатор поступают исходные 64 пикселя. Четыре выхода слоя нормализуются BatchNorm; далее используется сеть 68→6→10. Полная модель содержит **506 обучаемых параметров**, включая смещения и нормализацию.

Топологические признаки вычисляются внутри каждого прямого прохода. Градиент проходит через них к свёртке и порогам. Внешнего кэша топологических признаков здесь нет. Все модели получают **одинаковое изображение 8×8**; дополнительные признаки из исходного разрешения 32×32 не используются ни одной ветвью.

## Эксперимент

Данные — оригинальный OptDigits: 1934 изображения официальной части TRA для обучения и 946 изображений CV для выбора настроек. Изображения 8×8 получены усреднением блоков 4×4 исходного бинарного изображения. Это не готовые векторы другого разбиения OptDigits.

Выполнены **102 обучения**: 17 архитектурных вариантов × 2 скорости обучения × 3 случайных инициализации. Сначала проверены 12 вариантов, включая двухполевой эйлеров слой, геометрические аналоги, MLP и шесть CNN. Затем, после частичных результатов первого пилота, добавлены пять однополевых вариантов: сокращение числа признаков позволяет сохранить шесть скрытых нейронов в бюджете 512 параметров. Это адаптивная разработка; второй пилот не объявляется заранее зарегистрированным независимым подтверждением.

Для каждой архитектуры выбрана скорость обучения по средней точности трёх запусков на CV. Контрольная точка каждого запуска выбрана по минимальной перекрёстной энтропии на той же CV. AdamW, скорости 0,003 и 0,01, weight decay 0,01, batch size 256, без аугментации. У всех вариантов одинаковое правило остановки: до 500 эпох, ожидание 80 эпох без улучшения, автоматическое продление до 1000 при позднем улучшении. По принятому критерию ни один запуск не остался с нерешённой проблемой достижения лимита эпох. Это не доказательство глобальной сходимости.

| Модель | Обучаемых параметров | Точность CV, среднее трёх запусков |
|---|---:|---:|
| Обычная MLP | 460 | 94,40% |
| Двухполевой обучаемый эйлеров слой | 469 | 94,79% |
| Однополевой эйлеров слой с замороженными фильтром и порогами | 492 | 95,00% |
| **Однополевой обучаемый эйлеров слой** | **506** | **95,38%** |
| Однополевой обучаемый слой площади | 506 | 95,49% |
| Однополевой обучаемый слой периметра | 506 | 95,14% |
| Однополевой обучаемый слой площади и периметра | 504 | 95,70% |
| **Лучшая из проверенных обычных CNN** | **507** | **96,51%** |

Замороженный вариант хранит 506 параметров; 14 из них не обновляются. Это абляция обучаемости при той же ширине классификатора, а не равенство числа обучаемых весов. Лимит 512 относится к параметрам; вычислительная стоимость, рабочая память и статистики BatchNorm им не уравниваются.

Лучшая обычная CNN: свёртка с двумя каналами → BatchNorm → ReLU → усреднение до 4×4 → классификатор 32→11→10. Она выбрана из шести конфигураций: 1/2/4 канала, с обходным путём исходных пикселей или без него. Это лучший найденный здесь контроль, **не доказанно лучшая возможная CNN**.

### Что говорят сравнения

- Обучаемый однополевой эйлеров слой лучше своего замороженного аналога на **0,388 процентного пункта**. Парные различия по трём инициализациям: +0,634, +0,211 и +0,317 п.п. Начальные параметры и ширина этих двух моделей совпадают точно.
- Он лучше MLP на 0,987 п.п., но использует больше параметров и другую структуру. Одного этого сравнения недостаточно для вывода о пользе топологии.
- Геометрический контроль площади и периметра лучше эйлерова слоя на **0,317 п.п.**, а CNN — на **1,128 п.п.**. Поэтому специфическое преимущество топологической агрегации не установлено.
- Различия измерены на выборке, по которой выбирались архитектура, скорость обучения и контрольная точка. Они описательные; статистическая значимость и перенос на новый тест не заявляются. Ранее просмотренные тесты этого проекта заново не читались и не выдаются за независимое подтверждение.

## Проверка обучаемости и корректности

Жёсткий оператор проверен на всех 512 бинарных масках 3×3 против независимого подсчёта компонент и отверстий. Сглаженная формула совпала с независимым интегрированием по уровням. Автоматические производные по полю и порогам прошли проверку конечными разностями.

Во всех обучаемых эйлеровых запусках градиенты ошибки классификации к фильтру, смещению и порогам ненулевые. В сохранённых моделях изменились и параметры, и выходные признаки. У всех замороженных вариантов изменения точно нулевые.

Для однополевого выбранного варианта, фиксированная иллюстративная инициализация 0: норма изменения фильтра 0,617, порогов 0,587, смещения 0,254; среднеквадратическое изменение четырёх ненормализованных выходов на первых 128 обучающих изображениях — 1,369. Это подтверждает обучение самой конструкции. Иллюстрация использует заранее определённый номер инициализации, а не самый удачный запуск.

Независимая загрузка **всех 102 контрольных точек** точно воспроизвела сохранённые вероятности, точность и перекрёстную энтропию. Проверены контрольные суммы исходников, ограничения числа параметров и идентичность начальных состояний пар «обучаемый/замороженный». Результаты: `layer_checks.json`, `results_audit.json`.

Графики: `validation_comparison.png`, `learned_parameters.png`.

## Границы результата и дальнейший выбор

Получен пригодный для включения в нейросеть обучаемый топологический оператор и отрицательный результат относительно сильных контролей этого пилота. Это уже позволяет отвергнуть для данного бюджета простое предположение, что замена геометрической агрегации эйлеровой автоматически улучшит классификацию.

Эйлерова характеристика теряет информацию, когда изменения числа компонент и отверстий компенсируются. Слой не доказывает устранения зацепления классов или другого препятствия выразительности. Он измеряет топологию обучаемых промежуточных полей. Полная модель не инвариантна к произвольным гомеоморфизмам.

Следующий содержательный эксперимент — раздельно использовать обучаемые признаки нульмерной и одномерной персистентности либо добавить топологическую агрегацию к пространственным признакам CNN. Причина выбора — проверить потерю информации при суммировании \(\beta_0-\beta_1\) и при глобальном агрегировании. Это гипотеза для дальнейшей работы; такие эксперименты в данный результат не включены.

Дифференцируемые эйлеровы операторы уже изучены в [DECT, ICLR 2024](https://arxiv.org/abs/2310.07630), а реализация кривых для плотных изображений обсуждается в [Scalable GPU-Accelerated Euler Characteristic Curves, 2025](https://arxiv.org/abs/2510.20271). Приоритет самой идеи не заявляется.

## Файлы для воспроизведения

- `euler_layer.py` — оператор, двухполевой классификатор и обычные контроли.
- `single_field.py` — однополевой вариант.
- `check_layer.py` — математические и градиентные проверки.
- `pilot.py`, `single_field_pilot.py` — обучение.
- `pilot_protocol.json`, `single_field/pilot_protocol.json` — зафиксированные настройки и контрольные суммы.
- `pilot_results.json`, `single_field/pilot_results.json` — все 102 запуска, включая кривые обучения.
- `audit_results.py` — повторное вычисление предсказаний и аудит контрольных точек.

Архив `learned_topology_study.zip` в родительской папке `outputs` содержит код, протоколы, контрольные точки, вероятности и подготовленные TRA/CV. В нём сохранена структура `outputs/` и `work/`, нужная скриптам. Для повторного аудита из корня распакованного архива: `python outputs/learned_topology/audit_results.py`. Для продолжения или повторения обучения: `python outputs/learned_topology/pilot.py`, затем `python outputs/learned_topology/single_field_pilot.py`; существующие результаты пропускаются. Версии среды перечислены в `environment.json`. Математическая проверка перезаписывает свой протокол, поэтому её следует запускать на отдельной копии архива, если требуется сохранить исходные контрольные суммы.
