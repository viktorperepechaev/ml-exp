# OptDigits WDEP: коэффициент дополнительных признаков 1

Заново обучены две MLP 72→6→10, по 508 параметров и по 10 инициализаций. Обучение и стандартизация — TRA+CV, 2880 изображений; оценка — WDEP, 943 изображения. Исходные признаки те же; коэффициент дополнительных признаков равен 1.

LR выбран по средней accuracy на CV в предыдущем сравнении коэффициентов. Число эпох фиксировано как целая часть медианы выбранных по минимуму CV CE эпох десяти запусков при выбранном LR. Здесь обе медианы целые. Все 20 моделей обучены и зафиксированы до чтения WDEP; после оценки настройки не менялись.

AdamW, weight decay 0.01, batch size 256. Инициализация seed 0–9, генератор перестановок 2026092800+seed. Усредняются accuracy отдельных моделей; ансамбля нет.

| Модель | LR | Эпох | Средняя CV accuracy, % | Средняя WDEP accuracy, % | SD WDEP, п.п. |
|---|---:|---:|---:|---:|---:|
| Геометрическая | 0.007 | 47 | 94.863 | 95.334 | 0.719 |
| Топологическая | 0.003 | 94 | 95.476 | 96.564 | 0.581 |

Разность топология − геометрия: **+1.230 п.п.**; положительных пар по seed 10/10, отрицательных 0/10, равных 0/10.

SD отражает разброс по инициализациям. WDEP уже использовалась в исследовании, и её авторы почерка встречаются в обучении. Это повторная оценка новой конфигурации; статистическая значимость и обобщение на новых авторов этим запуском не устанавливаются. WINDEP не читалась.

## Воспроизведение

Из корня репозитория:

```bash
uv run --locked python evaluate_wdep_alpha1.py --workers 4
```

Скрипт создаёт новый каталог runs/wdep-alpha1-ДАТА и отказывается заменять существующий. Требуется сохранённый подбор runs/feature-scale-20261011. Протокол и его источники, обучающие и тестовые признаки, веса, кривые обучения, предсказания и проверка сохраняются вместе с отчётом.
